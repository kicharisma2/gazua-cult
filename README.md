## ⚡ 실시간 멀티플레이 서버 연동 안내

### 1. 웹사이트 vs 호스트 서버의 차이
- **웹사이트 ([kicharisma2.github.io](https://kicharisma2.github.io/gazua-cult/))**: 전 세계 누구나 24시간 언제든 화면을 볼 수 있는 **'고정 주소 모니터'**입니다.
- **호스트 서버 (`가즈아교_글로벌서버.exe`)**: 신도들의 실시간 움직임과 대화를 중계해 주는 **'멀티플레이 게임 서버'**입니다.

### 2. 가장 쉬운 원클릭 연동 방법
호스트 PC에서 **`가즈아교_글로벌서버.exe`**를 실행하면 콘솔창에 아래와 같은 링크가 생성됩니다:
```text
🌟 [GitHub Pages 원클릭 실시간 공유 링크]:
    👉 https://kicharisma2.github.io/gazua-cult/?server=https://[무작위영문].trycloudflare.com
```
이 링크를 복사하여 친구들에게 보내주시면, 친구들은 복잡한 서버 주소 입력 없이 **클릭 한 번으로 깃허브 웹사이트에서 즉시 🟢 실시간 멀티플레이에 입장**하게 됩니다!

## 🎮 주요 게임 시스템

1. **신도 계급 20단계 (성장 & 승급 시스템)**
   - 방황하는 개미(Lv.1)부터 대양봉교 교주(Lv.20)까지 경험치(EXP)를 쌓고 승급
2. **오늘의 은혜 일일 미션**
   - 상승 점프, 성수 세례, 황금 황소 성물 터치, 마왕 토벌 등 매일 수행하는 신앙 미션
3. **공매도 마왕 토벌 레이드**
   - 계좌를 위협하는 음봉 악귀 마왕을 신도들과 합심하여 단두대와 성수로 퇴마
4. **남관 황금 황소 성물 & 숨겨진 황금 개미 보물**
   - 황소상을 터치하여 상한가 축복(이동속도 +35% 버프) 영접
   - 성전 구석에 숨겨진 보물상자를 열어 특별 경험치 획득
5. **실시간 멀티플레이 & 대화**
   - 실시간 위치 동기화, 점프, 말풍선 대화, 전 성도 간증 피드

## 💻 로컬 / 인터넷 멀티플레이 서버 실행 방법

```bash
# 1. 의존성 설치
pip install websockets

# 2. 글로벌 멀티플레이 서버 실행 (로컬 웹소켓 + Cloudflare 터널 자동 생성)
python start_online_server.py
```
- 실행 시 콘솔에 출력되는 **외부 공유 링크** 또는 **내부 와이파이 링크**로 친구들을 초대할 수 있습니다.
- GitHub Pages 사이트 상단의 `[🌐 서버 연동]` 버튼을 눌러 발급된 주소를 입력하면 웹에서도 실시간 멀티플레이로 연동됩니다.
